# Eveline: privacy policy

*Last updated: 10 October 2026*

Eveline is a single-player game. It does not collect, store or share any
personal information.

- **No accounts, no ads, no analytics, no tracking.** The game has no
  sign-in and contains no advertising or analytics code.
- **What stays on your device.** Your settings (graphics, sound,
  controls, difficulty) and your progress (for example, that you have
  reached Part 2) are saved on your device only, and are deleted when you
  delete the game.
- **Updates.** When it starts, the game checks this public repository on
  GitHub for a newer, signed update to its own content and downloads it if
  there is one. That request contains no information about you; like any
  web request it reaches GitHub's servers with your device's IP address,
  which GitHub handles under its own privacy statement
  (https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
  We do not receive or keep it.
- **Camera, microphone, photos, location, contacts.** The game does not
  use any of them.
- **Children.** The game is a horror game for older players and collects
  no data from anyone, children included.

If this policy changes, the new version will be posted here.
